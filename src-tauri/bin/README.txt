Dossier réservé aux binaires FFmpeg et FFprobe minimaux (licence LGPL v2.1+).

Ce répertoire est vidé des exécutables dans Git. Pour compiler localement les binaires minimaux :
  bash scripts/build-ffmpeg-minimal.sh

Sans exécutables dans ce dossier, NéoMeca se replie automatiquement sur ffmpeg et ffprobe du PATH système en développement.
