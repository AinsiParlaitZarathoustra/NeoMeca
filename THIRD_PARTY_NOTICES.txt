1. FFmpeg et FFprobe (profil minimal sous licence LGPL v2.1+)
----------------------------------------------------------------------

NéoMeca embarque des exécutables autonomes et minimaux de FFmpeg et FFprobe (version 7.1.1) pour la lecture de métadonnées vidéo et l'extraction d'images.

Ces binaires sont compilés exclusivement sous licence GNU Lesser General Public License (LGPL v2.1 ou ultérieure), sans aucun composant GPL ni non-free :
- Options de compilation strictes : --disable-everything --disable-gpl --disable-nonfree --enable-small
- Script de compilation reproductible : scripts/build-ffmpeg-minimal.sh (dans le dépôt NéoMeca)
- Code source officiel FFmpeg 7.1.1 : https://ffmpeg.org/releases/ffmpeg-7.1.1.tar.xz
- Empreinte SHA-256 de l'archive source : 733984395e0dbbe5c046abda2dc49a5544e7e0e1e2366bba849222ae9e3a03b1

Conformément à la LGPL v2.1, vous pouvez également remplacer les exécutables FFmpeg / FFprobe situés dans le dossier bin/ de l'application (ou placer vos propres versions dans votre PATH système après suppression des binaires embarqués).
